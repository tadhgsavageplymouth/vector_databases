# Travel Recommender System

This is a Python-based travel destination recommender system that uses vector similarity (cosine similarity) to match a user preferences with a list of predefined travel destinations. The system is designed for simplicity and demonstrates the basics of recommendation systems.

## Features

- Stores travel destinations as feature vectors.
- Recommends destinations based on similarity to user preferences.
- Utilises cosine similarity for recommendation ranking.
- Easy to extend with additional destinations or user preference vectors.

## Getting Started

### Prerequisites

- Python 3.7 or later
- The following Python libraries:
  - `numpy`
  - `scipy`
